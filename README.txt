SYLORA Frontend
1. Keep your existing index.html, css/style.css and js/script.js if already created.
2. Create the new HTML pages listed in the project.
3. IMPORTANT: Replace your existing js/script.js with the script.js in this package.
4. Copy the contents of css/pages-extra.css and paste them at the END of your existing css/style.css.
5. Open index.html in browser.
Pages: shop.html, product.html, cart.html, checkout.html, login.html, about.html, contact.html, ai.html.
The AI page is currently a frontend demo. Python + real AI API comes next.
